### 霸道了了在房间 · ryocube

给用 iPad 画画的亲友做的轻量陪伴网页。月云了被关进了一个紫色 cube，会按自己的作息吃饭、睡觉、唱歌，也会在你不理他时四处走动，想办法找出口。

[打开房间](https://ryocube.netlify.app/) · [使用指南](https://ryocube.netlify.app/guide)

### 适合什么时候用

在 iPad 上画画时，用 Safari 打开房间，通过系统的多任务功能把它放在 Procreate 或其他画画 App 旁边。界面和操作参考 iPad 系统样式，主要照顾触屏和小窗口使用；其他手机、平板和电脑浏览器也可以打开。

画画、学习或做事时，可以让他自己待着，也可以打开循环专注，让他陪你一起专注和休息。网页内还有单次闹钟和正向秒表“计时了了”，不需要下载安装。

### 为什么做这个

这个项目把桌宠的角色与日常行为放进了一个适合 iPad 浏览器的小空间，希望亲友画画时，旁边能有一只会自己找事做、也会对打扰作出反应的了了。功能围绕陪伴和轻量互动展开，尽量把画面留给角色，让设置和说明退到需要时才打开的地方。

房间会跟随设备本地时间变换昼夜，偶尔下雨、起雾或透进阳光。可以敲玻璃、拖动和拨动他，也可以在支持的设备上主动开启重力感应；台词大小、天气和房间方向都能调整，具体操作放在[使用指南](https://ryocube.netlify.app/guide)里。

### 使用前知道这些就够了

小窗口由 iPadOS 管理，是否支持以及如何打开取决于设备和系统版本。锁屏时不保证准点响铃，重要提醒请用系统时钟；刷新页面或被系统重新载入后，闹钟、循环专注和秒表都会清空。

### 本地运行与构建

这是一个静态网页项目，角色图片、台词和音效已包含在 `assets.js` 中，不需要访问原桌宠仓库，也不需要安装第三方依赖。在仓库目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000`，即可本地预览。

使用 Node.js 20 或更新版本运行 `npm run build`，会生成可直接部署的 `publish` 目录；`npm test` 用于检查作息、计时和互动逻辑。仓库中的 `netlify.toml` 已设置构建命令与发布目录，现有在线版本继续托管在 Netlify。
